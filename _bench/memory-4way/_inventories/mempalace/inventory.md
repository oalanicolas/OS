## Notable Design Decisions

- **Verbatim always** — nao summariza, nao paraphrase, retorna palavras exatas
- **Incremental only** — append-only ingest, crash-safe
- **Entity-first** — chave por real names com disambiguation
- **Zero API required** — core funciona 100% local, sem api keys
- **Performance budgets** — hooks <500ms, startup <100ms

## Limitations

- Python only (sem SDK TS)
- ChromaDB file lock no Windows reduz coverage
- Nao publica comparacao side-by-side contra Mem0/Zep (decisao de honestidade)

## Unique Selling Points

- 96.6% R@5 raw sem LLM (benchmark publico, reproducivel)
- Local-first, zero cloud, zero API keys no caminho core
- Temporal KG em SQLite (vs Zep Neo4j cloud)
- Verbatim policy protegida no CONTRIBUTING
