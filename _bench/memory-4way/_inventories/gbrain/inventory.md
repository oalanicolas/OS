## Notable Design Decisions

- Contract-first: `src/core/operations.ts` define ~41 operations, CLI e MCP gerados daqui
- Engine pluggable: PGLite default (2s, sem servidor), Postgres pra 1000+ files
- Auto-link sem LLM: heuristicas para attended/works_at/invested_in etc
- Thin harness, fat skills: inteligencia nas skills markdown, runtime magro

## Limitations

- OAuth 2.1 nao implementado (ChatGPT bloqueado)
- Paraphrase-first storage (compiled_truth primario, raw em raw_data)

## Unique Selling Points

- BrainBench publicado: R@5 83 -> 95%, graph-only F1 86.6% vs grep 57.8%
- PGLite default ready em 2s (WASM)
- Minions: 753ms vs 10s+ em sub-agents, 100% durability
