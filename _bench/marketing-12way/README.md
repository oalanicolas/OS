## Top 3 achados

1. **"Platform" é commodity word.** 9 de 12 vendors se autodenominam "platform". Dizer isso é dizer nada. Espaço para AIOX fugir do rótulo (e.g. "operação", "BPO digital", "OS de agentes").

2. **Pain narrative é raro e caro.** Só 5/12 nomeiam a dor explicitamente. O melhor é Knowledge Plane ("Engineering teams move fast. Code gets refactored. Docs get updated. Decisions get made. But your AI tools are still working off last month's context."). Pain narrative de 4 frases curtas com virada é a estrutura mais afiada do benchmark.

3. **Zero vendors falam PT-BR sério nem verticalizam compliance brasileira.** CrewAI tem Piracanjuba como logo mas todo o site é inglês. Salesforce/Microsoft cobram em dólar. Angle LGPD/BACEN/stack brasileiro + pricing em R$ + squad brasileiro é diferenciação ainda inexplorada.
