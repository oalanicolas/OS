## Lethal questions

1. **Is the unit a skill, a spec, a persona, or an employee?** If you cannot answer, you will glue four systems and blow the listing budget.
2. **What is always-on?** If the answer is “all the SKILL.md bodies,” you already lost.
3. **Where does progress live after compaction?** If the answer is “the chat,” Superpowers already measured that failure (re-dispatch of finished tasks).
4. **Who is allowed to spend money / merge / talk to the user?** Only paperclip (money) and openclaw (allowlists) have a real answer. Everyone else is prompt text.
