## Dimension Analysis

### Epistemology (18%) — VISA 96 / gbrain 82 / others ≤70

VISA é o único com camadas A/B/C e `AgencyFinding` distinto de claim de counsel (`Epistemology-Layers.md`). gbrain tem takes vs facts — o par mais próximo — mas não bloqueia “score interno = finding do governo”. spec-kit/LifeOS têm SoT de spec/ISA, não de prova.

### Projection Integrity (14%) — VISA 94 / gsd-pi 86 / spec-kit 84

Hot-index e dashboard são projeções com fingerprint; portal não é vault. gsd-pi deriva STATE de checkboxes. spec-kit persiste spec/plan/tasks. gbrain: markdown é SoT, Postgres é cache. Dual-SoT é o burn do gsd histórico — VISA já cortou.

### Workspace Isolation (14%) — VISA 96 / gsd-pi 82 / paperclip 80

Um case root explícito; kit ≠ dados; nunca varrer irmãos. Mais fail-closed que OAuth-por-source do gbrain (leitura não é prefix-private). paperclip isola por `companyId`, mas o org-chart não é ACL.

### Extract-before-reviewed (14%) — VISA 95 / superpowers 88

A dimensão que mais separa doutrina de enforcement. `apply-batch` *rejeita* reviewed sem extract. Superpowers pede brief+review por prompt — o modelo ainda pode mentir. Ninguém mais no campo tem o gate mecânico.

### Graph Honesty (12%) — VISA 93 / mempalace 78 / gbrain 62

VISA: índice + Boundary Card + `SAME_ORIGIN_GROUP`. mempalace: temporal KG honesto (supersede atômico). gbrain: signals fail-open reordenam top-K — o anti-pattern que o lesson pack já cravou. Peers sem grafo = n/a, score baixo de propósito.

### Collector ≠ Auditor (12%) — VISA 94 / superpowers 90

`$review` + `$counsel` em sessão limpa; coverage ≠ elegibilidade. Superpowers quase empata no *software*. gbrain pensa com a mesma mente que escreve. paperclip tem QA/board, não lentes de counsel.

### Human/Data Split (8%) — VISA 94 / LifeOS 88

Voice Card não carrega prova. LifeOS é o runner-up legítimo (USER/ISA). paperclip colapsou SOUL no `AGENTS.md` do CEO.

### Process Spine (8%) — VISA 92 / gsd-pi 90 / Superpowers 90 / spec-kit 88

Quase empate técnico entre case phases e software spines. VISA soma freeze/pack fail-closed + fala de close honesta (“catálogo amplo ≠ deep review”).
